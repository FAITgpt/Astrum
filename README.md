# The ASTRUM Program Portal

**AD ASTRA. CUM FIDE.**  
The ADAM Institute at Elton

A private digital-academy MVP for personalized spacepower, mission-assurance, cybersecurity, AI/autonomy, and mission-systems education.

## Included
- Individual authentication via Supabase
- Student / mentor / admin roles
- 60-source ASTRUM Archive seed
- 10 Phase II produced source modules
- Progress tracking
- Weekly work plans
- Work diary and engagement-hour/unit tracking
- Mentor visibility for assigned students
- Row Level Security
- ASTRUM dark visual identity

## Deploy
Start with `DEPLOYMENT_GUIDE.md`.

## Database
Run `supabase/setup_all.sql` once in a new Supabase project's SQL Editor.

## Environment variables
Copy `.env.example` values into Vercel Project Settings -> Environment Variables.

## Security boundary
Read `SECURITY_AND_PRIVACY.md` before using the portal with real student data.
